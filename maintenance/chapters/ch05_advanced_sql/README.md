# Chapter 5: Advanced SQL

This folder contains the maintained materials for the one class meeting assigned to
selected Chapter 5 topics.

## Student-facing files

- `student_guide.md`: self-contained reading, worked examples, activities, and review.
- `student_lab.sql`: executable SQLite trigger, recursion, ranking, windowing, and
  conditional-aggregation examples. Run the Chapter 2 setup first.
- `standard_routine_examples.sql`: textbook-style SQL/PSM function and procedure
  examples. They are reference code and are not executable in SQLite.

## Instructor-only files

- `instructor/coverage_and_verification.md`: source locations, scope decisions,
  alignment, guidance, and verification record.
- `instructor/verify_ch05.py`: automated checks for every executable result and
  documented trigger behavior.
