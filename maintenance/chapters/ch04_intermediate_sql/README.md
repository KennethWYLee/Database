# Chapter 4: Intermediate SQL

This folder contains the maintained materials for the one class meeting assigned to
Chapter 4.

## Student-facing files

- `student_guide.md`: self-contained reading, worked examples, activities, and review.
- `student_lab.sql`: executable SQLite examples and practice prompts. Run the Chapter 2
  `course_registration_setup.sql` file first.

## Instructor-only files

- `instructor/coverage_and_verification.md`: source locations, scope decisions,
  teaching alignment, guidance, and verification record.
- `instructor/verify_ch04.py`: automated checks for query results, constraints, views,
  transaction behavior, and documented failures.
