# Database Management

Student-facing materials for **Database Management** at National Taipei University of
Business.

## Start Here

1. Open the [18-week course index](course/README.md).
2. Select the current week.
3. Read the linked chapter material before running a lab.
4. Write your prediction before execution and compare it with the observed result.
5. Retain the evidence requested on the weekly page.

## Course Files

- [Course syllabus](SYLLABUS.md)
- [Weekly course index](course/README.md)
- [SQLite setup, chapter readings, and lab files](resources/README.md)

The lab runner requires Python 3 and SQLite 3.39 or later. No server database or
third-party Python package is required.

```powershell
py -3 resources/run_labs.py --list
```

On Windows, replace `py -3` with `python` if that is the command configured by your
installation. On macOS or Linux, replace it with `python3`.
