## Textbook

Ramez Elmasri and Shamkant B. Navathe. *Fundamentals of Database Systems*,
7th Edition. Pearson.

## Course Description

Learn relational databases, SQL, ER modeling, and normalization through diagrams
and SQLite examples. Selected topics include indexing and transactions.

## Course Materials

One notebook per chapter. Start with this syllabus, then the introductory selections
in [Ch1](ch01.ipynb), [Ch2](ch02.ipynb), and [Ch5](ch05.ipynb).
The instructor sets stopping points; first-day programming is not required.
GitHub displays saved outputs; use a Python 3 notebook with SQLite 3.39+ to run examples.
Previous materials under revision are not assigned.
